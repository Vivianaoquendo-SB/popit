¿Qué es Pop It?

Pop It se traduce literalmente como "reviéntalo". Es un juego infantil cuyo proceso se puede comparar con reventar plástico de burbujas. Pero a diferencia del plástico de burbujas, los pop-its se pueden presionar con sensaciones y sonidos característicos "infinitamente": decenas de burbujas de silicona simplemente se empujan hacia el otro lado.

Reglas del juego

Los jugadores se turnan para presionar las burbujas. Es obligatorio terminar la fila que comenzaste. Se pueden presionar máximo 3 burbujas consecutivas (obligatoriamente deben estar juntas, no se pueden presionar varias burbujas a la vez si no están pegadas). El objetivo es hacer que el oponente presione la última. ¡Quien presiona la última pierde!
